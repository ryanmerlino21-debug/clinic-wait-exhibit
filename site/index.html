How do staffing and queue length affect clinic wait times?

A small neural network, trained on 2,000 simulated clinic visits, predicts patient wait time from the hour, weekday, staff on shift and number of patients waiting. Use it to explore scenarios, then check how reliable the predictions are on visits the model never saw.

–average error on test visits (min)

–held-out test visits
  1. Set a scenario in the simulator and read the predicted wait.
  2. Compare staffing levels or find the smallest staff count that meets a target wait.
  3. Check reliability in the results, then read how the model was built.
  4. Ask questions in the optional chat, which answers from the exhibit guide.

Note: the data is simulated. This is a teaching exhibit, not a tool for planning real clinic staffing.

6. Data, guide and limitations

Data source

The data is clinic-wait-times.csv from the Neural Network Explorer course site. It contains 2,000 simulated visits and is synthetic (made up), not drawn from real patients.

Limitations

  • The model describes a simulation, not a real clinic.
  • It has not been tested on any other dataset.
  • Predictions outside the training ranges (weekends, more than 5 staff, queues above 20) are not meaningful.
  • Chatbot answers can be wrong. Check them against this page.
